# Rotating-field three-body model-use release v0.1.0

Initial public release of the matrix-SCM and ML3B runtime package.

Included:

- matrix-SCM and fixed-geometry triplet calculations;
- physically constrained SCM pair-map interpolation;
- 120-feature permutation-invariant ML3B runtime;
- triplet and cluster APIs/CLI;
- refined pair map, model metadata, examples, tests, and CI.

The trained 5.77 GB model is hosted at Zenodo DOI `10.5281/zenodo.21512150` and can be downloaded with the verified asset command documented in the README.

This release does not contain the numerical datasets or plotting/table-generation scripts used for the article figures and tables.
