# Changelog

All notable changes to this project are documented here.

## 0.1.0 — 2026-08-07

### Added

- Installable matrix-SCM, geometry, pair-map interpolation, invariant-feature, surrogate-runtime, and cluster APIs.
- Command-line tools for one-triplet inference, cluster inference, direct SCM calculations, and verified model download.
- The refined SCM pair-interaction map, model metadata, internal model-selection metrics, examples, tests, and GitHub Actions.
- A model card, security guidance, release checklist, and machine-readable asset manifest for Zenodo DOI `10.5281/zenodo.21512150`.

### Release scope

- The 5.77 GB trained joblib model is hosted in Zenodo and is intentionally not tracked in Git.
- Numerical arrays and custom plotting/table-generation scripts underlying the article figures and tables are not part of this release.
- No numerical value in the manuscript was recalculated or changed during repository preparation.
